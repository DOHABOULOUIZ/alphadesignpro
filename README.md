# AlphaDesignPro

Site vitrine statique : accueil, studio et journal, portfolio, services.

## GitHub Pages
Publier le contenu de ce dossier à la racine du dépôt `alphadesignpro`.
Dans Settings → Pages, choisir Deploy from a branch, branche main, dossier / (root), puis Save.

Le fichier index.html est la page d’accueil. Aucun build ni installation n’est nécessaire.
Le formulaire prépare un message WhatsApp au +212 621 531 398 ; le visiteur confirme son envoi dans WhatsApp.

Le domaine personnalisé adp.abonus.ma pourra être configuré après la publication et la modification DNS. Aucun fichier CNAME n’est ajouté avant cette configuration.
